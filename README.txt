A minimalist, aesthetic Chrome New Tab extension with live seconds.

✨ Features
Live seconds display

Aesthetic Pink & Black gradient theme

Essential developer shortcuts

Google search bar integrated

🚀 How to Install
To install, follow these steps:

Download the files.

Create a folder and place the downloaded files inside.

Go to: chrome://extensions/ Make sure developer mode is enabled.

In the upper left corner, click "Load unpacked" and select the folder you created.

Done!
